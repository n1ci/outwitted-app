Privacy Policy for outwitted-upload

Effective date: 20 November 2026

This Privacy Policy describes how the application outwitted-upload (“the application”) accesses, uses, stores and shares Google user data. The application is a private desktop tool used by the operator of the YouTube channel “Outwitted” to upload and schedule videos to that channel. It runs only on the operator’s own computer. See also the application homepage.

1. Google user data the application accesses

When the user signs in with Google and grants permission, the application requests these OAuth scopes of the YouTube Data API v3:

  • https://www.googleapis.com/auth/youtube.upload: to upload video files, together with their title, description, tags, category, language and privacy settings, to the signed-in user’s own YouTube channel.
  • https://www.googleapis.com/auth/youtube.readonly: to read the name of the signed-in user’s channel and the list of videos on that channel that are scheduled for publication, in order to pick the next free publishing date.

The application does not access email addresses, contacts, comments, subscribers, analytics, payment data or any other Google user data.

2. How the data is used

Google user data is used only to provide the functions described above: uploading the operator’s own videos and scheduling them on the operator’s own channel. It is not used for advertising, profiling, market research, training of AI or machine-learning models, or any other purpose.

3. Storage and retention

  • The OAuth access and refresh token is stored only in a local file on the operator’s computer, readable only by the operator’s user account. It is never sent anywhere except to Google’s servers.
  • For each upload, the application writes a local log entry with the video ID, the video link and the scheduled publication time.
  • The application has no server, no database and no cloud storage of its own.
  • Local data is kept until the operator deletes it. Deleting the token file ends the application’s access on that computer.

4. Sharing and disclosure

Google user data is not sold, rented, transferred or disclosed to any third party. The only data transfer is between the operator’s computer and Google/YouTube through the official YouTube Data API.

5. Limited Use

The application’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

6. YouTube API Services

The application uses YouTube API Services. By using it, users agree to the YouTube Terms of Service. Google’s handling of data is described in the Google Privacy Policy.

7. Revoking access and deleting data

Access can be revoked at any time on the Google security settings page (myaccount.google.com/permissions). After revocation the stored token no longer works. The local token file and upload log can be deleted at any time; the application keeps no other copies.

8. Cookies and tracking

Neither the application nor this website uses cookies, analytics or tracking.

9. Children

The application is not directed at children and is used only by the channel operator.

10. Changes

Changes to this policy are published on this page with a new effective date.
